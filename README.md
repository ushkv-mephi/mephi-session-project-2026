## 1. Настройка сети

Сетевой интерфейс настроен по DHCP. Имя хоста:

```text
mephi-2026.domain.local
```

Сетевая связность проверена с помощью `ping 8.8.8.8`.

## 2. Управление программным обеспечением

Система обновлена через `dnf`. Установлены:

```text
nginx
libcap-ng-utils
```

Пакет `tcpdump` скачан через `dnf download` и установлен локально с помощью `rpm`.

## 3. Управление файловыми системами

На втором диске создан раздел с файловой системой `ext4` и меткой:

```text
MEPHI_WEB
```

Раздел автоматически монтируется в `/mephi-web` через `/etc/fstab`.

## 4. Управление сервисами

Сервис `nginx` запущен и включён в автозагрузку. Журнал текущей загрузки сохранён в `journalctl.out`.

## 5. Управление доступом

Созданы пользователи `user1`, `user2`, `user3` с UID `5501`, `5502`, `5503` и группа `curators` с GID `4444`.

Для `/data/mephi-2026` настроены ACL: разработчики имеют доступ на чтение и запись, кураторы только на чтение, остальные пользователи доступа не имеют.

Для `/usr/sbin/tcpdump` установлены:

```text
cap_net_admin,cap_net_raw=ep
```

SELinux работает в режиме `Enforcing`. Для `/mephi-web` используется контекст `httpd_sys_content_t`.

## 6. Аутентификация

Для группы `curators` запрещён локальный вход через PAM.

Максимальный срок действия пароля:

```text
90 дней
```

Минимальная длина пароля:

```text
12 символов
```

## 7. Тестирование

В `/mephi-web/index.html` создана web-страница:

```text
Hello from Student: 374415
```

Работа nginx проверена командой:

```bash
curl http://localhost/
```
